# 하루 세 칸 스페인어

번역원 업무(스페인·중남미 출판), 판소리·여성국극 논문, 워킹맘 일상에 맞춘 하루 20분 스페인어 루틴 앱.
단일 HTML 파일(`index.html`)이며 claude.ai Artifact로 발행해 휴대폰에서 씁니다.
같은 설계의 영어판([english-study-content](https://github.com/jaejugirl-sketch/english-study-content))을 스페인어로 옮긴 것입니다.

## 설계 전제

- **꾸준함이 난이도보다 먼저다.** 하루는 세 칸(말하기 7분 / 읽기 8분 / 단어 5분)이고,
  다 못 하는 날은 **한 칸만 해도 연속일이 유지**된다. 0으로 돌아가지 않게 하는 게 핵심.
- **소재는 전부 실제 쓰는 상황.** 범용 회화 교재 대신, 스페인어권 기관 회의·지원사업 설명·
  도서전 부스·판소리 설명·학회 질의응답 같은 실제 장면만 넣는다.
- **초급에서 시작한다.** 영어판이 B1–B2를 전제했다면 이쪽은 A1–A2다. 그래서
  ① 문법 한 조각이 하루에 하나씩 돌고 ② 읽기 소스가 학습자용 뉴스부터 시작하고
  ③ 코치가 접속법·완료시제로 문장을 끌어올리지 않는다.
- **읽기는 완독하지 않는다.** 8분 안에 ① 제목과 첫 단락 ② 표현 세 개 ③ 한 문장 요약.

## 영어판과 다른 점

| | 영어판 | 스페인어판 |
|---|---|---|
| 수준 | B1–B2 | A1–A2 |
| 문법 | 없음 | `GRAMMAR` 14개가 날짜 기준으로 하루 하나씩 (말하기 탭) |
| 발음 | 없음 | 오늘 탭에 고정 카드 다섯 줄 (스페인어는 철자와 소리가 거의 1:1) |
| 코치 | 고친 문장 / 왜 / 한 단계 위 / 한마디 | 여기에 **발음** 한 줄 추가, A2 밖으로 안 나가게 제약 |
| 단어 덱 | 업무·회의·학술·판소리·일상 | 기초·생존 / 동사 변화 / 업무·정책 / 문화·공연 / 일상·관심사 |
| 저장 키 | `haru3-v1`, `…/state` | `haru3-es-v1`, `…/state-es` (영어판과 섞이지 않게) |

영어판에 있던 버그 하나를 여기서는 고쳤습니다. `.view{display:flex}`가 브라우저의
`[hidden]` 규칙을 덮어써서 탭을 눌러도 화면이 숨겨지지 않고 다섯 화면이 한 장에 쌓입니다.
`.view[hidden]{display:none}` 한 줄이면 됩니다 — **영어판에도 같은 수정이 필요합니다.**

## 화면

| 탭 | 하는 일 |
|---|---|
| 오늘 | 세 칸 현황, 발음 다섯 줄, 요일별 읽기 소스, 바쁜 날 최소 루틴 |
| 말하기 | 오늘의 문법 한 조각 + 13개 상황 — 질문 3개, 핵심 표현 5개, 모범 답변, 내 답변 피드백 |
| 읽기 | 요일별 소스 + 보관함(제목·링크·요약·표현 저장) + 12개 소스 목록 |
| 단어 | 간격 반복(1·3·7·14·30일), 덱 5개 + 내가 모은 표현 |
| 기록 | 연속일·최장·세 칸 완료일, 최근 4주 그리드, 단어 상자 분포 |

## 내용 수정하는 곳

`index.html` 안의 `<script>` 상단 데이터만 고치면 됩니다.

- `SCENARIOS` — 말하기 상황 13개. `{id, group:'업무'|'논문'|'일상', title, when, prompts[3], phrases[[es,ko]], model, tip}`
- `GRAMMAR` — 문법 조각 14개. `{id, title, point, ex[[es,ko]], drill}`
- `WORDS` — 단어 73개. `[id, deck, term, ko, example]`. `DECKS`에 덱 이름이 있어야 보입니다.
- `SOURCES` — 읽기 소스 12개. `{id, name, url, level:1|2|3, topic, why, how}`
- `WEEK` — 요일별 배치. 인덱스 0=일요일. `src:null`이면 보관함 정리일.

말하기 상황과 문법 조각은 모두 날짜 기준으로 순환하므로(`dayNum() % 길이`),
개수를 늘리면 같은 항목이 돌아오는 주기도 길어집니다. 지금은 상황 13일, 문법 14일 주기.

## 저장

- **진도**: `db` 런타임 기능. `data/users/<viewer id>/state-es` 문서 하나에
  `{progress, vocab, library, mine}`를 담아 기기 간에 이어집니다. 이 경로는 본인만 읽습니다.
- **로그인 전/불가**: `localStorage`(키 `haru3-es-v1`)로 폴백. 기능은 그대로 동작합니다.
- **피드백**: `sample` 기능으로 Claude에게 교정을 요청합니다. 프롬프트는 `COACH_BASE`.
  고친 문장 / 왜 / 발음 / 한 단계 위 / 한마디 다섯 줄 형식을 강제합니다.

## 발행

```
Artifact 도구로 index.html을 같은 URL에 다시 발행
capabilities: {"db": {}, "user": {}, "sample": {}}
```

`capabilities`를 생략하면 기존 선언이 유지됩니다. 빈 객체 `{}`는 전체 해제입니다.

## 읽기 소스

처음 한 달은 Practica Español(EFE 통신의 학습자용 뉴스)과 Korea.net 스페인어판에서 시작합니다.
배경지식이 있거나 레벨이 표시된 글이 같은 난이도의 다른 글보다 훨씬 빨리 읽히기 때문입니다.
익숙해지면 El País Cultura·Centro Virtual Cervantes를 거쳐 Babelia·Letras Libres로 올라갑니다.
링크는 개별 기사가 아니라 매체 섹션 URL이므로 시간이 지나도 깨지지 않습니다.
업무용으로는 FIL 과달라하라와 LIBER를 넣었습니다 — `convocatoria`, `solicitud`, `plazo` 같은
공고문 어휘가 실제 문서 그대로 나오는 곳입니다.
